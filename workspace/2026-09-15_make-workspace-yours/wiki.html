JUPITER WIKI / GET STARTED

Jupiter

A desktop workspace for working with AI agents: chat with them, keep what they make, and teach them how you like to work.

Start here

Jupiter puts real Claude Code and Codex sessions next to a Workspace that keeps their results as readable cards, reports and files.

Everything lives in one folder on your computer as ordinary files. Skills teach the agents recurring tasks, the knowledge folder remembers your decisions, and Capabilities adds tools such as a browser, current library docs and pixel art kits.

Install and set up

One installer, one folder and a short setup wizard. No cloning or terminal needed.

Guide

Download

Get the latest version from GitHub Releases.

ComputerFileNotes
Windows…-windows-x64-setup.exeInstalls for your user only; no administrator rights. If SmartScreen warns, choose More info → Run anyway.
Mac (Apple Silicon)…-macos.dmgDrag Jupiter to Applications. The first launch may ask for confirmation.
Linux…-x86_64.AppImageMake it executable and run it.

First launch

Jupiter asks where to keep your workspace. Documents\Jupiter is suggested; any folder works. If you pick a folder that already has files in it, a Jupiter folder is created inside it. The workspace starts with skills, knowledge, workflows and the sample cards.

The setup wizard

The wizard opens over a blurred Workspace. Leave it at any point and return with Back to setup, or reopen it later from Settings → Run setup again.

01You

Your name, and what Jupiter should call you in greetings and replies.

02Projects

The folder that holds your projects. It can be anywhere, including an existing code folder. Change it later from the project picker.

03Agents

Git and Node.js come first, because the tools need them. Then Claude Code and Codex. Install opens a terminal running the official installer so you can see exactly what runs. Sign in opens the agent so you can log in with your Claude or ChatGPT account.

04Tools

The free starter set, installed after one confirmation: working methods, document and design skills, a browser for checking UI, current library docs and three pixel art tools. Tools already on your computer are taken over so Jupiter can keep them up to date. See Capabilities.

05Voice

Optional. Paste an ElevenLabs API key and pick a voice, and Jupiter reads its replies aloud. See Voice.

Your first task

The everyday loop: ask, let the agent work, review the card, decide.

Guide

Step by step

  1. In Chats, press +, choose Claude Code or Codex, pick a working folder and give the chat a clear name.
  2. Describe the result you want. Drop reference files or folders into the chat when they help.
  3. Let the agent work. A glowing logo marks activity; an unread marker shows a result you have not looked at yet.
  4. Open the Workspace card, compare its tabs and images, then give your decision back in the chat.
  5. Keep revisions as tabs on the same card. Archive the card when you are done; its files are kept.

Things to try

AskWhat happens
“Read my project brief and turn it into a small plan. Ask me for anything missing.”The plan skill produces a plan card with deliverables and checks.
“Compare these three concepts and put the findings in a Workspace card.”A report card with one tab per concept.
“Turn my brainstorm board into a game wiki.”The game-wiki skill builds a wiki like this one.
“Remember that I want reports short and in British English.”The preference is saved to context/preferences.md.
Permissions

Agents ask before they run commands or change files. Bypass is a per-chat choice, off by default; use it only when you trust the task.

Chats and agents

Real terminal sessions for your agents, docked beside the Workspace.

Reference

Agents

AgentSign in withNotes
Claude CodeClaude Pro or Max, or an Anthropic API keyGets the starter plugins, skills and MCP servers.
CodexAn eligible ChatGPT plan, or an OpenAI API keyThe default for new chats; change it in Settings.
OpenCode, KimiTheir own provider setupOptional; appear in + once installed.
ShellNothingA plain PowerShell or shell terminal.

Working with chats

  • Dock: Chats sits on the right. Drag the divider to resize, X to hide, and the Chats icon in the left navigation to bring it back. Hiding keeps sessions running.
  • Tabs: drag to reorder. Pinned tabs stay ahead of the rest.
  • History: find, reopen and pin earlier conversations. Restoring a chat relies on the agent's own session files.
  • Handoff: when a chat gets long, ask for a handoff. A summary is saved to inbox/handoffs/ and a fresh chat starts from it.
  • Files and images: dropping files inserts their paths; pasting a screenshot saves it in inbox/ and inserts that path.

Useful controls

ControlBehaviour
Ctrl+C in an agent chat (Windows, Linux)Copies selected text; it does not interrupt the agent
Ctrl+C in a shell chatThe normal interrupt
⌘C (macOS)Copies selected text
Ctrl+V (⌘V on macOS)Pastes text or a clipboard screenshot
Ctrl+S while editing MarkdownSaves the document

Workspace and cards

Where results are kept, compared and decided on.

Reference

The dashboard

The dashboard greets you by name and opens its panels from the tiles:

PanelWhat it shows
ProjectsYour cards, newest and pinned first
To doA board of tasks you drag between columns
BrainstormA canvas for notes, connectors and sketches
NewsHeadlines by topic, which Jupiter can read aloud
Agents and chatsRunning chats, grouped by agent
CapabilitiesInstalled skills, tools and connections
Token usageWhat your sessions have used, by model
ArchiveCards you or the age rule moved out of the active list

Cards

A card is one task or project. Its tabs are the pages inside it: reports, Markdown, images or a whole wiki. Cards are registered in workspace/workspace.json and their files live in a dated folder under workspace/.

  • Keep related revisions as tabs on one card, not one card per image.
  • Images open full size and can be downloaded.
  • Markdown tabs have Preview and Edit; Edit page works on editable report cards.
  • Archiving changes the card's status only. Sample cards stay until you archive them.

The Files view

Files shows the real folders. Select a file to preview it; Markdown opens with Preview and Edit. Dragging a file onto another folder moves it. Delete sends it to the Recycle Bin (the Trash on macOS and Linux). Hover a folder to open it in Explorer or Finder.

Boards and to do

Think on a canvas, track work on a board, and let agents read both.

Reference

Brainstorm boards

A free canvas for notes, text, images, connectors and pen sketches. Each board is saved to knowledge/boards/ with a readable Markdown summary beside it, so an agent can turn it into a plan or a wiki.

To do

A task board with columns you drag cards between. The first board is made from knowledge/todo.md; boards are saved in knowledge/work/. Ask Jupiter “what is on my list?” to hear it.

Billing

Agent subscriptions, the OpenAI voice API and ElevenLabs are billed separately by each provider. Local Whisper runs on your computer for free.

From your phone

With Tailscale on both devices, Chats → phone button shows a QR code. Scan it, confirm the six-digit code on both screens, and your phone can follow chats, read Workspace cards and send messages. The agents keep running on your computer.

Skills

Packaged know-how. A skill stays out of the way until a task needs it, then the agent loads it and follows its steps.

Reference

Where skills live

LocationUsed byWhat is there
.agents/skills/Codex, in this workspaceThe workspace skills. This is the copy to edit.
.claude/skills/Claude Code, in this workspaceComplete copies of the same skills for Claude Code.
~/.agents/skills/Codex, everywhereSkills installed from Capabilities, such as document and pixel art skills.
~/.claude/skills/ and Claude pluginsClaude Code, everywhereSkills and plugins installed from Capabilities.

~ is your user folder, for example C:\Users\you. A skill is a folder with a SKILL.md and sometimes scripts or references.

Skills in your workspace

01Planning and organising
  • plan: turns a broad request into a small plan with deliverables and checks.
  • feature-handoff: a precise handoff for another agent or developer.
  • workspace-authoring: how cards, report tabs and Markdown deliverables are made.
  • game-wiki: builds a wiki like this one from brainstorm boards and notes.
02Images, video and generation
  • image-reference-workflow: explore image concepts and make faithful edits.
  • fal-ai-generation, higgsfield-workflow: paid image, video, audio and 3D generation with your own account.
  • character-sheet-pipeline, motion-reference-workflow: references for 3D characters and motion.
  • video-watch: inspect a video through sampled frames and a visual report.
033D and game production
  • 3d-production-routing: picks the right workflow for a 3D or game task.
  • img2threejs: rebuild an object or character as a procedural Three.js model.
  • blender-game-animation, materials-to-game, game-animation-integration.
  • game-vfx-workflow, game-ui-workflow, game-audio-workflow, game-level-design, gameplay-visual-review.
04Research and voice
  • firecrawl: web research and scraping with your Firecrawl account.
  • voice-dictation-setup: set up local Whisper dictation.

Adding or changing a skill

  • Ask an agent: “Make this repeatable as a skill.” It writes the folder under .agents/skills/.
  • Received a skill pack? Copy the complete skill folders into .agents/skills/ and install only what their instructions require.
  • Your edits are yours: updates never overwrite a skill you changed.

Capabilities

Add, update and remove tools for your agents, each pinned to a reviewed version.

Reference

The tabs

TabMeaning
HarnessThe working method agents follow on every task: how they plan, build, test and review
SkillsPackaged know-how loaded when a task needs it
MemoryContext kept between sessions, such as earlier decisions or a map of your code
ToolsLet agents act outside the chat: a browser, library docs, Unity, Blender, generation, pixel art
Token BillTools that show or reduce what each session costs
ConnectionsThe MCP servers your agents can use, and whether each answered when last checked

The starter set

ToolWhat it gives your agents
Karpathy guidelinesFour short principles that keep changes simple, focused and checked
SuperpowersBrainstorm, plan, build test-first and review before calling it done
Document skillsWord, PDF, PowerPoint and Excel files done properly (Codex; Claude has them already)
UI UX Pro MaxStyles, palettes, font pairings and UX rules for interface work
PlaywrightA real browser to click through your app and take screenshots
Context7Current documentation for the libraries you use
PixelFX, Claude PXL, PixelboltPixel art effects, sprites, sheets and animations

How installs work

  • Reviewed: before installing you see what a tool adds, including hooks that run automatically.
  • Pinned: each tool is fixed to a commit or version. Check again compares it with the latest and offers an update.
  • Reversible: removing a tool undoes exactly what it added.
  • Can't check means the tool is on your computer but was not installed by this workspace. Run setup again to take it over.
  • Paid services such as Higgsfield, fal.ai and Firecrawl are optional and use your own accounts.

Updates

New versions arrive by themselves, and your own edits are kept.

Reference

How it works

Jupiter starts→Checks for a new version→Banner: install and restart→Skills and samples refreshed
  • Updates are signed; Jupiter installs only a version that passes the signature check.
  • Skills, workflows, rules and the sample cards are refreshed with each update.
  • A file you edited or deleted is never overwritten. A file you never touched is updated.
  • Tools in Capabilities update separately, when you choose to.

Keys and privacy

What needs a key, where it is stored and what never leaves your computer.

Reference

Optional keys

Keys live in .env in your workspace folder. The Voice step writes the ElevenLabs key for you; add others only if you use them.

KeyUsed for
ELEVENLABS_API_KEYSpoken replies
OPENAI_API_KEYThe live voice coordinator
FAL_KEYImage, video and 3D generation with fal.ai
OPENROUTER_API_KEYCloud dictation (local Whisper is the free default)

What stays local

  • .env, agent logins, chat histories and context/me.md stay on this computer.
  • Your workspace is plain files. To use it on another computer, keep it in Git or a synced folder; then install Jupiter there and sign in again.
  • Never paste keys into chats, cards or tracked files.

Troubleshooting

Common problems and the quickest fix.

Help

Problems and fixes

ProblemFix
Windows says it protected your PCThe installer is not code-signed yet. Choose More info → Run anyway.
An agent is not found after installing itThe Agents step checks again every few seconds. If it still is not found, restart Jupiter so it picks up the new PATH.
Tools step is lockedInstall Git, Node.js and Claude Code on the Agents step first.
A tool says “Can't check”It was installed outside this workspace. Settings → Run setup again → Tools.
A tool install failedRead the message in the Tools step; most failures are a missing agent or no network. Try again from Capabilities.
Jupiter does not speakCheck the ElevenLabs key in setup step 5 and that the key has Text to Speech access.
The update failedRestart Jupiter to try again, or download the latest installer from GitHub Releases and run it over the top.
A chat will not resumeResuming needs the agent's own history on this computer. Start a new chat, or use a handoff.
Ask Jupiter

In any chat: “Read AGENTS.md, find out why this is not working, and propose a small fix.” Agents can read this workspace and its logs.
