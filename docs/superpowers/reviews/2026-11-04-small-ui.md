# Small UI fixes: sidebar search and tool card (4 November 2026)

## Sidebar search: remove placeholder, keep clear of the icon

- **Cause (reproduced):** `.desktop-root input { padding: 10px 12px }` in `src/desktop/desktop.css` has the same
  specificity as `.sidebar-search input` in `src/styles/global.css` and loads later, so the 30px left padding
  reserved for the icon was lost. The caret and placeholder started under the magnifier.
- **Change:** `src/components/Sidebar.tsx` drops the placeholder and swaps the tiny text glyph for an inline SVG
  magnifier (`aria-hidden`); `src/styles/global.css` adds `.sidebar .sidebar-search input { padding: 7px 28px 7px 30px }`
  (higher specificity) and makes the icon a flex box.
- **Checked** (isolated service and Edge, probe `.cache/overnight/small-ui/probe-sidebar2.mjs`):
  empty field has no placeholder; text starts 7px after the icon (icon right edge 36px, text start 43px); the clear
  button sits at 259px, clear of typed text; `/` focuses the field; typing filters (2 cards to 1); the clear button and
  Escape both empty the field, Escape also blurs; no console errors. Accessible name `Search entities` unchanged.
- **Tests:** `navigation-ui` 16 of 16 pass; `capabilities-ui` passes. `workspace-edit-ui` fails at line 49
  (waiting for a "Show archive" button) **both before and after** this change; the same failure reproduces in an
  untouched copy of the source built separately, so it is not caused by this work.
- **Not verified:** a true light theme capture. The probe could not switch the service's theme preference, so the
  light screenshots still render dark. The change only uses existing variables, so it should carry over.
- Screenshots: `.cache/overnight/small-ui/sidebar-after-dark-focus.png`, `sidebar-after-dark-1400-typed.png`,
  `sidebar-after-dark-700-focus.png`.

## Tool Card Visual Bug: version label pushed out of the Pixelbolt card

- **Cause (reproduced):** `.jh-cap-card > footer` was a non wrapping flex row. With the studio running, the footer holds
  View on GitHub, Open Editor, Stop editor and the version label; in the narrower cards of a three column grid
  (about 310 to 340px) the row overflowed and the version ended outside the card (right edge 1397px against a card edge of 1333px at an 1800px window).
- **Change:** `src/styles/dashboard.css`: footer gets `flex-wrap: wrap` with a row gap; the version label is `nowrap`.
- **Checked** (probe `probe-toolcard.mjs`, studio state faked through a route override): after the fix the version stays
  inside the card at 1400, 1800 and 2200px, both running and stopped, and drops onto its own line beside Stop editor
  when space runs out. No console errors. Other cards (Unity, Blender, PixelFX) unchanged.
- Screenshots: `.cache/overnight/small-ui/toolcard-before-running-1800.png`, `toolcard-after-running-1800.png`.
- Studio open and close behaviour was not touched; the real studio was not launched.
